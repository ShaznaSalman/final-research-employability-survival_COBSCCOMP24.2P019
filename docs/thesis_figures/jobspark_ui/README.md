# JobSpark UI screenshots

Taken from the final redesigned app (branch `ui/jobspark`) in a real browser (Microsoft Edge, automated).

- `light-desktop`, `dark-desktop`: 1280 x 900 window, full-page screenshots.
- `light-phone`, `dark-phone`: 390 x 844 phone window, full-page screenshots.
- Files are numbered in the order a user meets the pages: home, the four profile steps, dashboard, improve, compare, job market, ask, research lab.
- `chatbot-and-top-bar`: the floating robot assistant (closed, open, no profile yet) and the top-bar light/dark switch and profile avatar.

The graduate profile used for the dashboard, improve, compare and ask pages is the app's default profile (no real person's answers). Screenshots are not committed to git.
