## Missing-value rules

| Field(s) | Rule |
|---|---|
| Outcome fields (graduation month, Q17, Q17a, survey date) | Row excluded from training - outcome cannot be constructed (see exclusions table). |
| Skill items (Q18, Q19) | Block mean uses the answered items if at least 67% of the block is answered; otherwise the block mean is missing and imputed (training-fold median) in preprocessing. |
| GPA (Q6) | Replaced by the degree-class equivalent (Q6a) when blank; if both are blank, imputed with the training-fold median in preprocessing. |
| Counts (Q9, Q12, Q13) | Internship months = 0 when Q11 = No. Otherwise imputed with the training-fold median in preprocessing. |
| Degree type (Q4), university type (Q3) | Imputed with the training-fold most frequent level in preprocessing. Unmapped university names are listed below. |
| Gender (Q2) | Kept as missing; shown as its own group in the fairness check (suppressed if n < 20). |
| Out-of-range / invalid values | Set to missing, then handled by the rule for that field. Never silently corrected (e.g. a GPA of 34 is not turned into 3.4). |
| Duplicate submissions | Rows identical on every answer (ignoring row id and timestamp) - the earliest submission is kept. |
