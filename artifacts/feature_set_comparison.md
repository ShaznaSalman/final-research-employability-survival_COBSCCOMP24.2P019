# Feature-set comparison (core vs pre-specified alternatives)

_Generated by `python -m core.feature_sets` - do not edit by hand._

Every set is fitted on the training set (620 graduates, 467 events) and scored on the validation set (133 graduates); the locked test set is not used. Hyperparameters are tuned on validation as in `core/evaluate.py`; differences come with a 1000-resample bootstrap of the validation graduates (no refitting).

## Sets

- **Core** (10 columns, EPV 46.7): gpa, degree_group, university_type, internship_months, certifications_count, project_count, technical_mean, soft_mean.
- **Extended** (16 columns, EPV 29.2): core + Portfolio before completion (Q14), Years of preparation (Q20), Self-learning frequency (Q21), Hackathons / events (Q23), Open-source contribution (Q24), SDLC familiarity (Q29).
- **Transformed** (11 columns, EPV 42.5): core information with log(1 + count) for internship months, certifications and projects, plus an indicator for GPA >= 3.0 (functional forms fixed in advance from human capital and signalling theory).

## Pre-registered decision rule

A set replaces **core** only if, for Cox PH, the improvement in validation Uno's C is at least 0.01 **and** it is better in at least 70% of bootstrap resamples; and either its EPV is at least 10 or Elastic Net Cox meets the same criteria. If more than one set passes, the one with the larger improvement is recommended. Combinations of sets are not tested.
